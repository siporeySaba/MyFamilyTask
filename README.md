# אפליקציית משימות לילדים

גרסת MVP ראשונית. עובדת כרגע על **localStorage** (בלי Firebase עדיין) כדי שאפשר יהיה
לראות ולבדוק את הזרימה המלאה מיד. שכבת הנתונים כולה מרוכזת בקובץ `js/db.js` —
כשנחבר Firestore, נחליף רק את המימוש הפנימי שם, בלי לגעת במסכים עצמם.

## הרצה מקומית
צריך שרת סטטי פשוט (לא לפתוח את ה-HTML ישירות מהדיסק, כי מודולי ES6 חוסמים
בקשות מ-`file://`). למשל:

```
cd kids-tasks-app
python3 -m http.server 8080
```

ואז לפתוח `http://localhost:8080` בדפדפן.

## מבנה
```
index.html         מסך בחירת ילד + גריד המשימות היומי
setup/              אשף הגדרת משפחה: שם, ילדים, בחירת עד 10 מתוך 15 משימות + נקודות
admin/              מסך הורה: שיעורי בית להיום + איפוס יתרת נקודות
js/db.js            שכבת נתונים (localStorage כרגע → Firestore בהמשך)
js/taskCatalog.js   קטלוג 15 המשימות הקבועות (אימוג'י placeholder לתמונה)
css/style.css       עיצוב, RTL מלא
```

## מה עדיין חסר (בכוונה, לשלבים הבאים)
- **Firebase Auth + Firestore אמיתי** — כרגע הכל נשמר רק בדפדפן הנוכחי (משפחה אחת,
  בלי multi-tenant אמיתי, בלי login).
- **החלפת האימוג'י בתמונות אמיתיות** שתכין — פשוט להחליף `emoji` ב-`imageUrl` בקובץ
  `taskCatalog.js` ולעדכן שורה אחת ב-`main.js` (רינדור `<img>` במקום טקסט).
- **תמונות ילדים אמיתיות** — כרגע שדה URL טקסטואלי במסך ה-setup; אפשר להחליף
  להעלאת קובץ + Firebase Storage.
- **שיעורי בית עם תמונה** (בנוסף לטקסט).
- **גרף התקדמות שבועי** (כרגע רק פס התקדמות יומי).
- **פינת איחולים מההורים** (פיצ'ר עתידי).
- **מצב Kiosk בטאבלט** — ברמת מערכת ההפעלה (Screen Pinning באנדרואיד / Guided
  Access באייפד), לא חלק מהקוד עצמו.

## נקודות (3 מונים, לכל ילד)
1. **סה"כ** (lifetime) — לא מתאפס לעולם.
2. **יתרה למימוש** (redeemable) — מתאפסת ידנית מה-admin כשהילד מקבל תגמול.
3. **היום** (daily) — מתאפסת בחצות, ולפני האיפוס מצטרפת אוטומטית ליתרה.
